# ADR-0006 - Utilização do GitHub como plataforma de versionamento

## Status

**Accepted**

## Data

24/07/2026

## Autor

Fábio Alves da Silva Santos

---

## Contexto

Toda a documentação, scripts, manifests e diagramas do laboratório precisam ser versionados para garantir rastreabilidade e facilitar a evolução do projeto.

---

## Problema

Definir a plataforma de hospedagem do repositório.

---

## Alternativas Consideradas

- GitHub
- GitLab
- Azure DevOps

---

## Decisão

Utilizar o **GitHub** como plataforma principal de versionamento.

---

## Justificativa

- Plataforma amplamente utilizada pela comunidade.
- Excelente integração com GitHub Actions.
- Suporte nativo à renderização de Mermaid.
- Facilidade para compartilhamento da documentação.
- Interface intuitiva para navegação do projeto.

---

## Consequências

### Positivas

- Histórico completo de alterações.
- Facilidade de colaboração.
- Integração com ferramentas do ecossistema DevOps.

### Negativas

- Dependência de um serviço externo para hospedagem do código.
